# secrethound 기획서

## 개요
Git 레포지토리(현재 파일 + 전체 커밋 히스토리)에서 유출된 API 키, 토큰, 인증정보 등 민감 정보를 자동으로 탐지하는 시크릿 스캐너.

## 목적
- 개발자가 실수로 커밋한 시크릿을 배포/공개 전에 미리 찾아내는 도구 제작
- 보안 도메인 지식(탐지 로직 설계)과 실제 동작하는 결과물을 함께 보여주는 포트폴리오

## 핵심 기능
1. **패턴 매칭** — AWS/Slack/Stripe 등 형식이 정해진 시크릿을 정규식으로 탐지
2. **엔트로피 분석** — 형식이 없는 랜덤 문자열을 Shannon entropy 기반으로 탐지
3. **Git 히스토리 스캔** — 현재 파일뿐 아니라 과거 커밋에 남아있는 시크릿까지 탐지
4. **오탐 필터링** — 테스트/예시 코드 등 컨텍스트를 고려해 false positive 감소

## 결과물 형태
- CLI 도구 (`secrethound scan ./repo`)
- (선택) 웹 대시보드 — 스캔 결과 시각화
- (선택) GitHub Actions 연동 — PR에서 시크릿 발견 시 CI 실패 처리

## 차별화 포인트
- gitleaks/trufflehog 대비 오탐 감소 로직(파일 경로 컨텍스트 가중치 등)
- 결과를 보기 쉽게 보여주는 대시보드 UI

## 아키텍처

### 전체 흐름
```
[대상 레포 경로/URL]
        │
        ▼
┌─────────────────────┐
│ 1. Repo Collector    │  현재 파일 + git log -p 로 커밋 히스토리 전체 diff 수집
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│ 2. Detection Engine   │
│  ├─ Regex Matcher     │  AWS/Slack/Stripe/JWT 등 알려진 포맷 매칭
│  └─ Entropy Analyzer  │  임의 문자열의 Shannon entropy 계산 후 임계값 초과 시 후보로 등록
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│ 3. FP Filter          │  파일 경로(test/, example/), 변수명, 화이트리스트 규칙으로 오탐 제거
└─────────────────────┘
        │
        ▼
┌─────────────────────┐
│ 4. Reporter           │  탐지 결과를 파일:라인, 종류, 심각도로 정리
└─────────────────────┘
        │
        ├──▶ CLI 출력 (터미널 리포트)
        ├──▶ 웹 대시보드 (JSON → 시각화)
        └──▶ GitHub Actions (탐지 시 CI 실패 처리)
```

### 컴포넌트별 역할
| 컴포넌트 | 역할 | 비고 |
|---|---|---|
| Repo Collector | 현재 워킹 디렉토리 파일 + git 커밋 히스토리(diff) 수집 | 히스토리에서 지워진 시크릿도 잡아야 하므로 필수 |
| Regex Matcher | 알려진 시크릿 포맷을 정규식 룰셋으로 매칭 | 룰셋은 별도 설정 파일(yaml/json)로 분리해 확장 가능하게 |
| Entropy Analyzer | 정규식으로 못 잡는 랜덤 문자열 후보 탐지 | 임계값 튜닝이 오탐률에 직결 |
| FP Filter | 컨텍스트 기반으로 오탐 후보 제거 | 프로젝트 차별화 핵심 로직 |
| Reporter | 탐지 결과를 표준 포맷(JSON)으로 정리 | CLI/대시보드/CI가 공통으로 소비 |

### 동작 방식 (요약)
1. 사용자가 CLI로 스캔 대상 경로 지정
2. Repo Collector가 현재 파일 스냅샷 + 전체 git 히스토리 diff를 순회 가능한 형태로 수집
3. 각 텍스트 라인에 대해 Regex Matcher와 Entropy Analyzer를 동시에 적용해 후보 탐지
4. FP Filter가 컨텍스트(파일 경로, 주변 코드)를 보고 후보의 신뢰도 점수를 조정, 임계값 미달 항목 제외
5. Reporter가 최종 결과를 정리해 CLI 출력 / 대시보드용 JSON / CI 종료 코드로 내보냄

## 기술 스택
- **언어: Go**
  - 단일 실행 바이너리로 배포 가능 (설치 과정 없이 CLI 배포)
  - goroutine으로 파일/커밋 병렬 스캔에 유리
  - 정규식(`regexp`), 파일 순회, `os/exec` 기반 git 연동 모두 표준 라이브러리로 해결
- **CLI 프레임워크**: `spf13/cobra` (서브커맨드 구조, 플래그 파싱)
- **룰셋 설정**: YAML (`gopkg.in/yaml.v3`)
- **Git 연동**: `go-git` 또는 `git` 명령어 직접 호출 (추후 결정)
- **웹 대시보드**: TBD (Reporter의 JSON 출력을 소비하는 구조라 나중에 결정해도 무방)
