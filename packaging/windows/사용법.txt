secrethound — 유출된 API 키·시크릿 검사 도구
================================================

무엇을 하는 프로그램인가요
--------------------------

소스 코드에 실수로 적어 넣고 그대로 커밋해 버린 API 키·비밀번호·인증서를 찾아냅니다.

중요한 점은, 나중에 키를 지워도 **git 커밋 기록에는 그대로 남는다**는 것입니다.
지금 파일만 보면 깨끗해 보이지만 저장소를 공개하는 순간 과거 기록에서 키가 드러납니다.
secrethound는 현재 파일과 과거 커밋 기록을 함께 검사합니다.


쓰는 방법
---------

  방법 1. secrethound.exe 를 두 번 클릭합니다.
          폴더를 고르는 창이 뜨면 검사할 폴더를 선택하세요.

  방법 2. 검사할 폴더를 secrethound.exe 위로 끌어다 놓습니다.
          여러 폴더를 한꺼번에 끌어다 놓아도 됩니다.

검사가 끝나면 결과가 웹 브라우저에 자동으로 열립니다.

설치할 것은 없습니다. 압축을 푼 폴더에서 바로 실행하면 되고, 지울 때는 폴더째
삭제하면 됩니다. 레지스트리나 다른 위치에는 아무것도 남기지 않습니다.


여러 프로젝트를 한 번에 검사하기
--------------------------------

프로젝트를 모아두는 폴더(예: C:\projects)를 지정하면, 그 바로 아래에 있는
저장소를 전부 찾아 하나씩 검사합니다. 프로젝트마다 따로 실행할 필요가 없습니다.

검사할 폴더가 여럿이면 브라우저 탭이 그 수만큼 열리지 않도록, 결과 파일이 모인
폴더를 대신 열어줍니다.


결과 파일
---------

검사가 끝나면 이 폴더에 결과 파일이 생깁니다.

  secrethound-report-폴더이름.html   브라우저에서 보기 좋은 형태
  secrethound-report-폴더이름.md     메모장·노션·깃허브에 붙여넣기 좋은 형태

파일 이름에 검사한 폴더 이름이 들어가므로 어느 프로젝트의 결과인지 구분됩니다.
같은 폴더를 다시 검사하면 뒤에 -1, -2 가 붙어서 이전 결과가 지워지지 않습니다.

  secrethound-report-myrepo.html      (처음 검사)
  secrethound-report-myrepo-1.html    (같은 폴더를 다시 검사)

필요 없는 결과 파일은 그냥 지우면 됩니다.


키가 발견되면
-------------

**파일에서 지우기 전에, 발급한 곳에서 키를 먼저 폐기(revoke)하세요.**

파일에서 지우고 커밋해도 키 자체는 여전히 살아 있습니다. 이미 누군가 저장소를
복사해 갔을 수도 있습니다. 폐기가 먼저이고, 파일 정리는 그 다음입니다.

어디서 어떻게 폐기하는지는 결과 리포트의 "대응 방법" 항목에 키 종류별로 적혀 있습니다.


처음 실행할 때 파란 경고창이 뜬다면
-----------------------------------

"Windows의 PC 보호" 라는 창이 뜰 수 있습니다. 이 프로그램에 유료 코드 서명
인증서가 없어서 나오는 경고이며, 바이러스가 발견되었다는 뜻은 아닙니다.

  "추가 정보" → "실행" 을 누르면 실행됩니다.

미덥지 않으면 소스 코드를 직접 확인하고 빌드할 수 있습니다.
https://github.com/whiteclover0542/SecretHound


안전한가요
----------

  - 검사 결과는 어디로도 전송되지 않습니다. 전부 이 PC 안에서만 처리됩니다.
  - 리포트에는 키의 앞뒤 몇 글자만 남기고 가운데를 가려서 싣습니다.
    리포트 파일이 또 다른 유출 경로가 되지 않게 하기 위해서입니다.
  - 발견한 키가 지금도 살아있는지 발급처에 물어보는 기능이 있지만,
    기본적으로 꺼져 있습니다. 켜야만 외부로 요청이 나갑니다.


과거 커밋 기록까지 검사하려면
-----------------------------

git 이 설치되어 있어야 하고, 검사할 폴더가 저장소의 최상위 폴더여야 합니다.
조건이 안 맞으면 오류 없이 "지금 있는 파일만 검사했습니다"라고 알려줍니다.


이 폴더의 파일들
----------------

  secrethound.exe   이걸 두 번 클릭하세요
  사용법.txt        이 파일
